# kNN 유방암 진단 보조 시스템

scikit-learn의 위스콘신 유방암 데이터에 kNN 분류기를 적용해 최적의 k를 찾고, 그 결과를 바탕으로 만든 진단 보조 시스템을 웹사이트로 정리한 미니 프로젝트입니다.

**배포 사이트:** https://breastcancerreport.vercel.app/

## 결과 요약

| 조건 | 최적 k | 최고 정확도 | k = 13 정확도 |
|---|---|---|---|
| 원본 데이터 | 13 | 94.74% (108/114) | 94.74% |
| 표준화 후 (StandardScaler) | 3, 17, 18 | 98.25% | 97.37% |

- k가 작으면(1~8) 결과가 들쭉날쭉하고(과대적합), k가 크면(31 이상) 정확도가 서서히 떨어집니다(과소적합).
- k = 13 모델은 실제 악성 42개 중 4개를 양성으로 놓쳤습니다(악성 재현율 90.5%).
- kNN은 거리 기반이라, 특성을 표준화하면 정확도가 크게 오릅니다.

## 웹사이트 구성

| 섹션 | 내용 |
|---|---|
| 결과 한눈에 | 스크롤하면 작은 k → 최적의 k → 큰 k → 표준화 순으로 그래프가 바뀌는 단계별 설명, k 슬라이더 |
| 개요 · 데이터 · 방법 | 프로젝트 목표, 데이터 구성, 기본 실험과 표준화 실험 코드 |
| 결과 · 상세 | k 구간별 정확도, 114칸 정답 그리드, 혼동행렬과 정밀도·재현율 |
| 표준화 | 원본과 표준화 결과 비교 |
| 진단 시스템 | 표준화 + k = 13 설정으로 직접 판정해 보는 진단 보조 시스템 |
| 결론 | 결과 정리와 실험의 한계 |

### 진단 보조 시스템

분석에서 찾은 **표준화 + k = 13** 설정으로 악성 의심 / 양성 추정을 판정합니다. kNN은 페이지 안에서 JavaScript로 직접 구현했으며, 테스트 샘플 114개 전체에서 scikit-learn과 같은 판정을 냅니다.

- **테스트 샘플로 진단:** 114개 중 하나를 골라 판정하고 실제 진단과 비교합니다. "틀린 샘플 보기"로 모델이 틀린 3개를 확인할 수 있습니다.
- **직접 입력해 보기:** 최악 반지름, 평균 질감, 평균 오목점 수, 최악 오목점 수를 슬라이더로 조절하면 판정이 바로 바뀝니다. 나머지 항목은 학습 데이터 중앙값으로 채웁니다.
- **판정 근거 표시:** 가까운 이웃 13개의 투표 결과, 가장 가까운 이웃 5개, 신뢰도(12표 이상 높음, 10~11표 보통, 9표 이하 낮음)를 함께 보여 줍니다.

## 실험 설정

- 데이터: `sklearn.datasets.load_breast_cancer()` (569개 샘플, 30개 특성, 악성 212 / 양성 357)
- 분할: 학습 80% / 테스트 20%, `stratify=y`, `random_state=42`
- 모델: `KNeighborsClassifier(n_neighbors=k)`, k = 1~100
- 표준화: `StandardScaler`를 학습 데이터로만 맞추고 테스트 데이터에는 변환만 적용

## 한계

- 테스트 세트를 한 번만 나눠 평가했기 때문에 `random_state`에 따라 최적 k가 달라질 수 있습니다. 교차검증으로 보완할 수 있습니다.
- 테스트 데이터를 보고 k를 골랐으므로 최고 정확도는 실제 성능보다 조금 낙관적일 수 있습니다.
- 학습용 미니 프로젝트이며, 판정 결과를 실제 진단에 사용할 수 없습니다.
