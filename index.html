프로젝트 개요

가까운 이웃에게 물어보는 진단.

세포 검사 수치로 종양이 악성인지 양성인지 판별합니다. kNN은 새 데이터와 가장 가까운 학습 데이터 k개를 찾아 다수결로 답을 정합니다.

이번 프로젝트의 목표

  • KNeighborsClassifier(n_neighbors=k)에서 k를 1부터 100까지 바꿔 가며 테스트하기
  • 테스트 정확도가 가장 높은 k 찾기

데이터

569개의 샘플, 30가지 단서.

실험 방법

k를 100번 바꿔서.

데이터를 8:2로 나누고, stratify=y로 악성·양성 비율을 맞췄습니다. random_state=42로 고정해 언제 다시 돌려도 같은 결과가 나옵니다.

기본 실험 코드

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

cancer = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(
    cancer.data, cancer.target,
    test_size=0.2, stratify=cancer.target, random_state=42)

scores = []
for k in range(1, 101):
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(X_train, y_train)
    scores.append(model.score(X_test, y_test))

best_k = scores.index(max(scores)) + 1   # 13

표준화 실험 코드

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler().fit(X_train)   # 학습 데이터로만 맞춤
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test)

scaled_scores = []
for k in range(1, 101):
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(X_train_s, y_train)
    scaled_scores.append(model.score(X_test_s, y_test))

print(max(scaled_scores))   # 0.9825 (k = 3, 17, 18)
print(scaled_scores[12])    # 0.9737 (k = 13)

결론과 한계

k 선택만큼 중요한 전처리.

원본 데이터에서 최적 k는 13, 정확도는 94.74%였습니다. 표준화를 적용하면 같은 k = 13에서 97.37%, 최고 98.25%까지 올라, kNN에서는 전처리가 k 선택만큼 중요하다는 것을 확인했습니다.

이번 실험의 한계

  • 테스트 세트를 한 번만 나눠 평가했기 때문에, random_state를 바꾸면 최적 k가 달라질 수 있습니다. 교차검증(cross_val_score)으로 여러 번 평균을 내면 더 믿을 만한 k를 고를 수 있습니다.
  • 테스트 데이터로 k를 고르면 그 데이터에 맞춰진 결과가 되므로, 엄밀하게는 검증 세트로 k를 정하고 테스트 세트는 마지막에 한 번만 써야 합니다. 표준화 후의 최고 정확도 98.25%도 같은 이유로 실제 성능보다 조금 높게 나왔을 수 있습니다.
  • 의료 현장에서는 정확도보다 악성 재현율이 중요합니다. 실제 활용을 생각한다면 악성을 놓치지 않는 쪽으로 판정 기준을 조정하는 방법도 검토해야 합니다.
